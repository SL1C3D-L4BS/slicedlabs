# Founder scripts

Run by the founder only, from a normal terminal in `~/Projects/slicedlabs`. Agents never run them (ADR-0020, PLAN3-R11/R12).

- `approve-001-080.sh`: the one-shot close-out for episodes 001-080 (evidence, ADRs, Constitution, lifecycle, signed commit). It refuses to start, and waits before each `wo-verify`, while the machine is busy (load average above `--max-load`, a live factory builder, or foreign cmake/ninja/ctest/compiler/linker processes); `--ignore-load` overrides, `--preflight-only` runs the checks and exits (WO-127). Summary and change list: `build/closeout/approval-summary.md`.
- `resign-history.sh`: re-sign every commit on main before the first push. Rewrites every hash; read its warning.
- `commit-wos`, `preflight.sh`: earlier founder helpers (commit grouping by work order; pre-flight).
- `push.sh`: pushes `main` to `origin` (WO-115). Founder-run only, from a normal terminal in the repository: `bash scripts/founder/push.sh`. Preflight, in order: on branch `main`; tree clean (untracked files count); `origin` exists and answers `git ls-remote`; the remote `main`, if any, is an ancestor of local `main` (otherwise it refuses: never forces, never rewrites); `just fast` exits 0. It then lists the commits to push with their count, asks once, and pushes only when you type the word `yes` (anything else exits 1 with nothing pushed). The push is `main:refs/heads/main` with `--no-follow-tags` (plus `-u` when `main` has no upstream); tags are never pushed. It ends by printing the GitHub Actions URL derived from the remote URL. `--remote <url>` replaces `origin` and exists for the test only. Test: `just founder-push-test` (`tests/gates/founder_push_test.sh`, throwaway bare repositories under `build/`).
