# Episode records SL-EP-061 to SL-EP-080

Records for the twenty episodes of Volume 04, the Fabric, that work orders WO-035 to WO-063 built (SL-VOL-04-SPEC records
061-080; master plan section 6.1 record fields). The registry `registry/SL-REG-002-episodes.json` is authoritative
(master plan section 6.3 rule 1): every episode below is still `Planned` there, and this builder changes no status. The
founder runs `evidence-record` and `ep-advance` after the merge (SL-PLAN-003, ADR-0007). ADR-0020 caps episodes 061-080 at
Demonstrated until Volume 03 is Accepted and both ARCH documents are Approved; SL-ARCH-001 and SL-ARCH-002 are InReview
0.3.1 (released by WO-063 as 0.3.0, hardened by WO-064), not Approved. Evidence files `evidence/WO-035.json` to `evidence/WO-064.json` do not exist yet: the founder
records them after the merge, so every "evidence/WO-NNN.json" pointer below is pending founder close-out.

Machine under test (measured, `build/acceptance/10-fabric-gate.log`): clang 23.1.3, gcc 16.2.1 with libstdc++-16, cmake 4.4.4, ninja 1.13.2, just 1.59.0, Python 3.14.8, Arch Linux. Nothing here was run on Windows, on
GitHub Actions, on a GPU device or on a big-endian host.

Honest limits of the whole volume, repeated per episode where they bite:

- Durability is simulated: crash and lost-fsync behaviour is exercised through a faulty vfs and the exhaustive recovery
  sweeps, never by cutting power (seam S15, Volume 21).
- Windows is unverified: `vfs_win32` returns unsupported (seam S14, ADR-0006). Big-endian hosts are untested; every byte
  layout is little-endian by specification.
- Wall time is unmeasured. Performance cases are work-bound proxies (objects written, nodes visited, probes, fsyncs);
  wall-time benchmarks wait for Volume 16. The wall times quoted below are single observations on one machine, not a
  budget.
- Seams S1 to S13 (merge drivers, leases, operation-log transport, selective undo, branch policy, provenance across
  branches, packs and garbage collection, large-blob chunking, runtime state hashing, recorded clocks, schema-aware
  snapshot restore, branching replay, multi-process writers) are hooks only; each is owned by Volume 10, 17 or 18
  (SL-ARCH-002 "Open issues"). S16 (BLAKE3 and big-endian) is reserved, not adopted.
- Code changes the WO-062 reconciliation found were fixed by WO-064 (`work-orders/WO-064.md`, committed after this
  release's documents were written); the remainder is listed in the open issues of both ARCH documents for a later work
  order. The bullets below say which.

Observed exit codes and wall times below were measured in one session on the working tree of WO-063, one run of each
cited recipe. The per-area recipes `just fabric-test <area>` build preset debug and run one CTest label; they are in no
gate, so their exit codes are cited here. Recipes that `fabric-gate` and `check-full` run are cited through them.

## SL-EP-061 — Canonical identity algebra

### Done

- Record ids carry a class and a mint scheme (random, derived, well-known, imported), a canonical uppercase Crockford
  text form and a typed wrapper, with an entropy self test (WO-037). Object ids are in-house SHA-256 digests with a frame
  header (WO-037, WO-038 vectors).
- The identity lifecycle: tombstones keep the last record oid, an id is never reused except by the undo of the retiring
  transaction, instance, imported and derived ids are stable, and a record whose id class differs from its type's record
  class is rejected on commit (WO-058, FAB-INV-LC-01 to LC-05).
- The conformance suite runs the identity rows for every registered type (WO-062).

### Decisions

ADR-0011 (identity layout): ids, classes and mint schemes. ADR-0010 (the fabric error range 5000-5999) for the typed
failures such as `id_parse`, `id_class_mismatch` and `id_reuse`.

### Acceptance

- `just fabric-test id`: exit 0 observed (9.2 s wall, this run).
- `just fabric-test identity`: exit 0 observed (13.5 s wall, this run) (lifecycle rows).
- `just fabric-conformance`: part of `fabric-gate` (see SL-EP-079).

### Evidence

- `engine/fabric/include/sl/fabric/id.hpp`, `identity.hpp`, `tests/unit/fabric/id_*_test.cpp`,
  `identity_*_test.cpp`, `tests/fixtures/fabric/hash/vectors.json` (97 hashlib vectors checked by `fabric-vectors-check`).
- `evidence/WO-037.json`, `evidence/WO-058.json`: pending founder close-out.

### Open issues
