# WO-084 deviations: clocks and the determinism kit (episode 089)

Builder record for time.hpp, replay.hpp, src/time_*.cpp, src/rng_*.cpp, src/det_*.cpp, the eight clock_* and det_*
test files and the goldens tests/golden/runtime/rng_vectors.json and hash_vectors.json. SL-ARCH-003 was not edited.

## The frame clock counts the frame index

- Decision: `frame_clock::frame_index()` is the number of samples taken (one per begin_frame, ARCH3-R079); every
  sample counts, frozen or not. The clock contributor snapshots it.
- Why: the `determinism` row "logical tick, fixed-stepper accumulator, frame index" is snapshotted, but the brief's
  frame_clock has no frame index and the frame scheduler (WO-089) does not exist yet. RT-INV-CLOCK-03 checks that the
  frame index never decreases. WO-089 may read it or keep its own counter.
- Where: engine/runtime/include/sl/runtime/time.hpp `frame_clock::frame_index`, `frame_clock::state::frame_index`.
- Rule or table: ARCH3-R079, ARCH3-R081, `determinism`.

## Capture and restore on every clock, plus members beyond the brief

- Decision: `fixed_stepper::state` is {accumulator, dropped_ticks}; `frame_clock::state` is {previous_ns, has_previous,
  frozen, non_monotonic, dropped_ns, frame_index}; both have capture()/restore(). `logical_clock::restore(tick)` exists
  for snapshot restore only. Also added: `fixed_stepper::rate()` (the reduced rate), `max_catchup()`,
  `frame_clock::frozen()`, `max_frame_delta()`, `tick_scope::get()`, and the constants `max_frame_delta_default`
  (250 ms) and `max_catchup_default` (8) named from the `limits` table.
- Why: the clock contributor (ARCH3-R091) must capture and restore the stepper, the logical clock and the frame clock;
  the brief names only the stepper's capture/restore.
- Where: time.hpp `fixed_stepper`, `frame_clock`, `logical_clock`, `tick_scope`.
- Rule or table: ARCH3-R091, ARCH3-R174, `limits` max_frame_delta, max_catchup.

## frame_time field names and mutability

- Decision: `frame_time` is {frame_index, now (tick), delta (nanos), a (alpha {num, den})}, the brief's names, with
  plain (non-const) members: it is immutable by use (a value copied to jobs), not by type.
- Why: ARCH3-R081 spells the fields {frame_index, tick, delta_ns, alpha_num, alpha_den}; the brief decides the names.
  Const members would fail clang-tidy cppcoreguidelines-avoid-const-or-ref-data-members (warnings are errors) and
  make the value unassignable.
- Where: time.hpp `frame_time`.
- Rule or table: ARCH3-R081, `immutability` time::frame_time, `thread_safety`.

## Stepper arithmetic: reduced rate, 128-bit product in two words

- Decision: make() reduces num/den by std::gcd. advance() forms delta x num + accumulator as a pair of 64-bit words
  (32-bit-half multiply) and divides by the tick cost den x 10^9 (< 2^62) with a native division when the high word is
  0 and a shift-subtract long division otherwise, so every delta up to INT64_MAX ns is exact. A delta at or below 0
  adds nothing; ticks beyond u64 and dropped_ticks saturate. restore() of an accumulator at or above one tick is a
  Debug assertion and is reduced modulo the cost; the clock contributor rejects such bytes first.
- Why: the brief forbids unsigned __int128 and states the accumulator bound only for clamped deltas; advance() takes
  any nanos, and (max_catchup + 1) x den x 1e9 can exceed 2^64 for a 32-bit den.
- Where: engine/runtime/src/time_stepper.cpp `multiply`, `divide`, `fixed_stepper::advance`, `fixed_stepper::make`.
- Rule or table: ARCH3-R078, ARCH3-R080.

## Frame clock edge cases and RFP6 parameters

- Decision: a sample at or before the previous one returns 0, counts non_monotonic and leaves the baseline at the
  previous (highest) sample, so a backward jump never replays time. freeze() makes samples return 0 with no counter
  change; thaw() makes the next sample return 0 and become the baseline. RFP6 is visited once per non-frozen sample
  inside `#if SL_RUNTIME_FAULTS`: param 0 returns 0 and counts non_monotonic without moving the baseline; param p adds
  p ms to this frame's delta before the clamp (the baseline is the real sample, so the next delta is real). Differences
  are taken in unsigned arithmetic and dropped_ns saturates. max_frame_delta at or below 0 is a Debug assertion.
- Why: ARCH3-R079 and the `failpoints` RFP6 outcome do not say where the baseline goes after a backward sample, how a
  hitch persists, or how param values map; the brief says "param 0 = backward, param p = p ms hitch".
- Where: engine/runtime/src/time_frame_clock.cpp `frame_clock::sample`, `freeze`, `thaw`.
- Rule or table: ARCH3-R079, ARCH3-R026, `failpoints` RFP6.

## tick_scope asserts the scope prefix

- Decision: tick_scope keeps a non-zero current correlation id, else draws next_correlation_id(); a scope that does not
  start with "runtime/" is a Debug assertion.
- Why: ARCH3-R083 fixes the scope as runtime/<instance>; the brief leaves the check open.
- Where: engine/runtime/src/time_tick_scope.cpp `tick_correlation`.
- Rule or table: ARCH3-R083, ARCH3-R068.

## state_hasher: the str tag and the bool byte

- Decision: str is tag 0x31, then the u64le length, then the UTF-8 bytes (bytes stays 0x30); bool is 0x40 then one
  byte 0 or 1. finish() returns `sl::fabric::digest` {sha256, bytes} and leaves the state unchanged.
- Why: the brief lists str without a tag; a distinct tag keeps bytes("abc") and str("abc") apart, as the width tags keep
  u32(5) and u64(5) apart. Bytes reach sl::fabric::sha256 through a 64-byte chunk copy (no reinterpret_cast, which
  clang-tidy rejects).
- Where: engine/runtime/src/det_hasher.cpp `state_hasher::str`, `state_hasher::boolean`, `length_prefixed`.
- Rule or table: ARCH3-R088, `limits` canonical_nan_f32, canonical_nan_f64.

## merge_ordered callback, nulls and the selection step

- Decision: `merge_ordered(std::span<ordered_buffer<T> *const>, out)` calls `out(const ordered_key &, T &)` once per
  entry in key order (the value is a non-const reference so a consumer may move it out); null buffer pointers are
  skipped; the span must be spelled by the caller (T is not deduced from a vector). The smallest-head selection and its
  Debug assertion on a key repeated across buffers are out of line in `detail::min_head`. ordered_buffer stores a
  std::vector; push() may allocate and is not noexcept. Added `ordered_key_layout_version = 1` and `entries()`,
  `size()`, `empty()`, `clear()`, `reserve()`.
- Why: the brief leaves the callback signature and the buffer storage open; ARCH3-R032 needs an ordered_key layout
  version as a runtime_abi_digest input; the brief lists det_merge.cpp as a source.
- Where: engine/runtime/include/sl/runtime/replay.hpp `ordered_buffer`, `merge_ordered`, `ordered_key_layout_version`;
  engine/runtime/src/det_merge.cpp `detail::min_head`.
- Rule or table: ARCH3-R086, ARCH3-R032, `determinism` ordered_key.
- Analyzer note: gcc -fanalyzer (`just analyze`) reported "use of uninitialized value 'ordered_key::tick'" in the
  defaulted operator<=> on a path through std::ranges::sort in det_merge_test.cpp. Every ordered_key member already
  has an initialiser. The test now builds its keys in strictly increasing order, so the producers push their filtered
  share with no sort. No pragma.

## rng_stream details

- Decision: next_below(0) is a Debug assertion and returns 0 without drawing; capture() writes the engine under the
  classic locale; restore() parses into a copy of the engine (never a default-seeded one), rejects malformed text and
  trailing text with snapshot_corrupt and leaves the state unchanged; rng_stream has a defaulted operator==.
- Why: the brief does not name the restore error; snapshot_corrupt (6100) is the runtime code for state bytes that do
  not parse. A default-constructed std::mt19937_64 is a default-seeded engine (ARCH3-R087, clang-tidy
  bugprone-random-generator-seed).
- Where: engine/runtime/src/rng_stream.cpp `rng_stream::next_below`, `capture`, `restore`.
- Rule or table: ARCH3-R089, ARCH3-R087, `error_codes` snapshot_corrupt.

## Contributor byte layouts and hashes

- Decision: runtime.clock v1 is 58 little-endian bytes: tick u64, accumulator u64, dropped ticks u64, previous sample
  i64, has_previous u8, frozen u8, non_monotonic u64, dropped_ns u64, frame index u64; it hashes the tick only (u64).
  runtime.rng v1 is a u32le stream count then per stream a u32le length and the capture text; it hashes the count (u32)
  and each capture text (str). Both restore all-or-nothing and return snapshot_corrupt for a wrong length, a flag byte
  other than 0 or 1, an accumulator at or above one tick, a count mismatch, truncation or trailing bytes; capture
  appends to the vector. clock_contributor holds pointers to the three clocks; rng_contributor copies the span of stream
  pointers at construction (registration order). Both are declared in replay.hpp.
- Why: the brief names the contributors and their sources but no layout; the `determinism` table makes the tick (not
  the accumulator or frame index) hashed and the rng state hashed. Reference members fail clang-tidy
  cppcoreguidelines-avoid-const-or-ref-data-members.
- Where: engine/runtime/src/time_contributor.cpp `clock_contributor`; engine/runtime/src/rng_contributor.cpp
  `rng_contributor`; replay.hpp.
- Rule or table: ARCH3-R091, `determinism`, `thread_safety` snapshot_contributor (owner-thread, end_frame).

## Golden oracles

- Decision: both goldens were computed once by the stdlib-only Python script below (`python3 -I wo084-goldens.py
  <dir>`), independent of the C++ code: hashlib for SHA-256 and an own MT19937-64 checked against the C++ standard's
  [rand.predef] value (the 10000th draw of a default-seeded std::mt19937_64 is 9981545732273789042). rng_vectors.json
  has 16 (seed, stream) cases, each 8 x next_u64, then 4 x next_below(1000), then 2 x next_unit bit patterns from one
  stream in that order; hash_vectors.json has 40 cases of alternating (op, value) with floats as bit patterns. Each
  case is one line; the tests read them with a small line parser under SL_RUNTIME_SOURCE_DIR. No test writes them and
  no tools/runtime writer exists for them (paths_allowed has none); a change regenerates them with this script.
- Why: the brief asks for an oracle independent of the C++ code, recorded here.
- Where: tests/golden/runtime/rng_vectors.json, tests/golden/runtime/hash_vectors.json; tests/unit/runtime/det_rng_test.cpp,
  det_hash_test.cpp.
- Rule or table: ARCH3-R015, ARCH3-R088, ARCH3-R089.

```python
import hashlib, struct, sys

M = (1 << 64) - 1


class MT64:  # MT19937-64 (Matsumoto and Nishimura), the std::mt19937_64 parameters
    def __init__(self, seed):
        self.mt = [seed & M]
        for i in range(1, 312):
            p = self.mt[-1]
            self.mt.append((6364136223846793005 * (p ^ (p >> 62)) + i) & M)
        self.i = 312

    def next(self):
        if self.i >= 312:
            for k in range(312):
                y = (self.mt[k] & 0xFFFFFFFF80000000) | (self.mt[(k + 1) % 312] & 0x7FFFFFFF)
                self.mt[k] = self.mt[(k + 156) % 312] ^ (y >> 1) ^ (0xB5026F5AA96619E9 if y & 1 else 0)
            self.i = 0
        x = self.mt[self.i]
        self.i += 1
        x ^= (x >> 29) & 0x5555555555555555
        x ^= (x << 17) & 0x71D67FFFEDA60000
        x ^= (x << 37) & 0xFFF7EEE000000000
        x ^= x >> 43
        return x


def check_mt():  # C++ [rand.predef]: the 10000th draw of a default-constructed mt19937_64
    g = MT64(5489)
    for _ in range(9999):
        g.next()
    assert g.next() == 9981545732273789042


def rng(seed, stream):
    d = hashlib.sha256(b"slr-rng/1" + struct.pack("<QQ", seed, stream)).digest()
    return MT64(struct.unpack("<Q", d[:8])[0])


def below(g, n):
    t = ((1 << 64) - n) % n
    while True:
        x = g.next()
        if x >= t:
            return x % n


def unit_bits(g):
    v = float(g.next() >> 11) * 2.0 ** -53
    return struct.unpack("<Q", struct.pack("<d", v))[0]


PAIRS = [(0, 0), (0, 1), (1, 0), (1, 1), (42, 0), (42, 7), (5489, 0), (0xFFFFFFFFFFFFFFFF, 0),
         (0, 0xFFFFFFFFFFFFFFFF), (0x0123456789ABCDEF, 3), (0xDEADBEEF, 0xCAFEBABE), (2**63, 2**63),
         (123456789, 987654321), (7, 65536), (0x8000000000000001, 1), (1000000007, 42)]


def rng_vectors():
    lines = []
    for seed, stream in PAIRS:
        g = rng(seed, stream)
        u = ['"0x%016x"' % g.next() for _ in range(8)]
        b = ['"%d"' % below(g, 1000) for _ in range(4)]
        f = ['"0x%016x"' % unit_bits(g) for _ in range(2)]
        lines.append('{"seed": "0x%016x", "stream": "0x%016x", "u64": [%s], "below_1000": [%s], "unit_bits": [%s]}'
                     % (seed, stream, ", ".join(u), ", ".join(b), ", ".join(f)))
    return ('{"format": "slr-rng-vectors/1", "order": "8 x next_u64, 4 x next_below(1000), 2 x next_unit", '
            '"cases": [\n' + ",\n".join(lines) + "\n]}\n")


WIDTH = {"u8": (0x01, "<B"), "u16": (0x02, "<H"), "u32": (0x04, "<I"), "u64": (0x08, "<Q"),
         "i8": (0x11, "<b"), "i16": (0x12, "<h"), "i32": (0x14, "<i"), "i64": (0x18, "<q")}


def encode(op, v):
    if op in WIDTH:
        tag, fmt = WIDTH[op]
        return bytes([tag]) + struct.pack(fmt, int(v, 0))
    if op == "bool":
        return bytes([0x40, 1 if v == "true" else 0])
    if op == "f32":
        b = int(v, 16)
        if (b & 0x7F800000) == 0x7F800000 and (b & 0x007FFFFF):
            b = 0x7FC00000
        if b == 0x80000000:
            b = 0
        return bytes([0x24]) + struct.pack("<I", b)
    if op == "f64":
        b = int(v, 16)
        if (b & 0x7FF0000000000000) == 0x7FF0000000000000 and (b & 0x000FFFFFFFFFFFFF):
            b = 0x7FF8000000000000
        if b == 0x8000000000000000:
            b = 0
        return bytes([0x28]) + struct.pack("<Q", b)
    if op == "bytes":
        raw = bytes.fromhex(v)
        return bytes([0x30]) + struct.pack("<Q", len(raw)) + raw
    if op == "str":
        raw = v.encode("ascii")
        return bytes([0x31]) + struct.pack("<Q", len(raw)) + raw
    raise ValueError(op)


LONG = "".join("%02x" % (i * 37 % 256) for i in range(70))
CASES = [
    ("empty", []), ("u8_0", ["u8", "0"]), ("u8_255", ["u8", "255"]), ("u16_0x1234", ["u16", "0x1234"]),
    ("u16_max", ["u16", "65535"]), ("u32_5", ["u32", "5"]), ("u32_deadbeef", ["u32", "0xdeadbeef"]),
    ("u64_5", ["u64", "5"]), ("u64_max", ["u64", "0xffffffffffffffff"]), ("i8_m1", ["i8", "-1"]),
    ("i8_min", ["i8", "-128"]), ("i16_m2", ["i16", "-2"]), ("i16_max", ["i16", "32767"]), ("i32_m5", ["i32", "-5"]),
    ("i32_min", ["i32", "-2147483648"]), ("i64_m5", ["i64", "-5"]), ("i64_min", ["i64", "-9223372036854775808"]),
    ("bool_false", ["bool", "false"]), ("bool_true", ["bool", "true"]), ("f32_pzero", ["f32", "0x00000000"]),
    ("f32_nzero", ["f32", "0x80000000"]), ("f32_one", ["f32", "0x3f800000"]), ("f32_nan_quiet", ["f32", "0x7fc00000"]),
    ("f32_nan_signal", ["f32", "0x7f800001"]), ("f32_nan_negative", ["f32", "0xffc00001"]),
    ("f32_inf", ["f32", "0x7f800000"]), ("f64_pzero", ["f64", "0x0000000000000000"]),
    ("f64_nzero", ["f64", "0x8000000000000000"]), ("f64_1_5", ["f64", "0x3ff8000000000000"]),
    ("f64_nan_quiet", ["f64", "0x7ff8000000000000"]), ("f64_nan_signal", ["f64", "0x7ff0000000000001"]),
    ("f64_nan_negative", ["f64", "0xffffffffffffffff"]), ("f64_ninf", ["f64", "0xfff0000000000000"]),
    ("bytes_empty", ["bytes", ""]), ("bytes_3", ["bytes", "00ff10"]), ("bytes_70", ["bytes", LONG]),
    ("str_empty", ["str", ""]), ("str_clock", ["str", "runtime.clock"]),
    ("mixed_widths", ["u32", "1", "u64", "2", "f32", "0x80000000", "bytes", "61626364"]),
    ("mixed_key", ["u64", "600", "u8", "2", "u16", "7", "u32", "3", "u32", "11", "bool", "true", "f64",
                   "0x7ff4000000000000", "str", "runtime/demo"]),
]


def hash_vectors():
    assert len(CASES) == 40
    lines = []
    for name, ops in CASES:
        h = hashlib.sha256()
        for k in range(0, len(ops), 2):
            h.update(encode(ops[k], ops[k + 1]))
        lines.append('{"name": "%s", "ops": [%s], "sha256": "%s"}'
                     % (name, ", ".join('"%s"' % o for o in ops), h.hexdigest()))
    return ('{"format": "slr-hash-vectors/1", "ops": "alternating op and value; floats as bit patterns", '
            '"cases": [\n' + ",\n".join(lines) + "\n]}\n")


check_mt()
out = sys.argv[1]
with open(out + "/rng_vectors.json", "w") as f:
    f.write(rng_vectors())
with open(out + "/hash_vectors.json", "w") as f:
    f.write(hash_vectors())
```
