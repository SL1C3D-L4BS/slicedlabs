# WO-077 deviations

Builder record for tools/runtime (runtime_lint, contracts_check) and their gates. SL-ARCH-003 was not edited.

## tools/runtime is a Python package

- Decision: an empty tools/runtime/__init__.py was added, although it is not named in the paths_allowed of WO-077.
- Why: `just tools-test` is `unittest discover -s tools`, which enters a subdirectory only when it has an `__init__.py`
  (every other tools/ directory has one); without it test_runtime_lint.py and test_contracts_check.py would never run.
- Where: tools/runtime/__init__.py.
- Rule or table: ARCH3-R014 (the Python tests of RT-INV-LINT-01 to 04 run under `just tools-test`).

## The allow-list excuses the whole file of the failpoint registry

- Decision: lint_allow.json holds one entry, path engine/runtime/src/faults.cpp, rule R-RT-GLOBAL, symbol `*` (every
  symbol of that file and rule). A symbol other than `*` matches the variable name exactly. Entries are not checked for
  staleness (the file may not exist yet, and WO-076 owns the registry's shape).
- Why: WO-076 decides the registry's name and runs at the same time; naming it here would break one of the two orders.
  WO-100 may narrow the entry to the real symbol.
- Where: tools/runtime/lint_allow.json; runtime_lint.py `load_allow`, `check_tree`.
- Rule or table: ARCH3-R008.

## Rules and symbols beyond the brief

- Decision: a malformed lint_allow.json (not JSON, an entry without exactly path, rule, symbol, reason, an empty field,
  an unknown rule) is reported as rule R-RT-ALLOW, so there are 13 lint rules plus R-RT-ALLOW.
- Why: "an entry without reason is an error" needs a rule id; the fabric surface check names its own R-F5-ALLOW.
- Where: runtime_lint.py `load_allow`.
- Rule or table: ARCH3-R008.

## R-RT-LAYER

- Decision: only headers under include/sl/runtime that appear in the `layers` table are checked, and only their includes
  of `sl/runtime/...` (or a quoted relative path that resolves to a table entry). A header missing from the table is
  not an error. A same-layer cycle is every include edge inside a strongly connected component; a layer whose
  `headers` text says "neither includes the other" (L9) allows no same-layer include at all.
- Why: the table is the only authority; an unknown header cannot be ranked.
- Where: runtime_lint.py `load_layers`, `layer_findings`.
- Rule or table: ARCH3-R009; table `layers`.

## R-RT-FABRIC

- Decision: the scoped lists are exactly ARCH3-R004 and R005: include/ and src/ take the nine base headers; testing/ and
  tools/ add workspace, transaction and authority; vfs.hpp is accepted only in a file directly in src/ named
  platform_files*.cpp (testing/ and tools/ included, so `testing/` reaches the faulty vfs through the fabric testing
  headers, which are included by relative path and are not matched); store.hpp, f5.hpp and internal/** are refused
  everywhere. Only paths that contain `sl/fabric/` are examined.
- Why: the brief says "vfs.hpp only in src/platform_files*.cpp".
- Where: runtime_lint.py `fabric_findings`.
- Rule or table: ARCH3-R004, ARCH3-R005.

## R-RT-MATH

- Decision: a struct, class or using name is refused when it is vec, vector, mat, matrix, quat, quaternion, transform,
  fixed, simd, aabb or curve followed by a digit, an underscore or the end (vec3, mat4x4, transform_component,
  fixed_point), except `fixed_stepper`; the intrinsics headers are *mmintrin.h, x86intrin.h, arm_neon.h, arm_sve.h,
  experimental/simd and simd, beside the four named.
- Why: a bare prefix test would refuse material_slot or transformer; `time::fixed_stepper` is named by ARCH3-R078 and
  the error table.
- Where: runtime_lint.py `_BANNED_TYPE`, `_MATH_ALLOWED`, `math_findings`.
- Rule or table: ARCH3-R007, ARCH3-R078; ADR-0021.

## R-RT-GLOBAL

- Decision: a text scanner over blanked code (no C++ parser). It checks namespace-scope variables, `static` data members
  and `static` or `thread_local` locals. const and constexpr pass (a pointer needs `const` after the last `*`),
  thread_local never passes, constinit alone does not make a variable const. A direct-initialised `T x(1);` is read as a
  function declaration and is missed; so are variables declared through a macro.
- Why: no compiler is available to a stdlib-only tool (ADR-0004).
- Where: runtime_lint.py `global_findings`, `_global_statement`, `_is_const`.
- Rule or table: ARCH3-R008.

## R-RT-ORDER and R-RT-FENCE

- Decision: memory_order_consume is treated as weaker than seq_cst like the four named orders. The pairs comment is read
  from the raw line, so a `// pairs:` in a string literal would count.
- Why: consume is weaker than seq_cst; ARCH3-R058 says "weaker than seq_cst".
- Where: runtime_lint.py `_ORDER`, `order_findings`.
- Rule or table: ARCH3-R057, ARCH3-R058.

## R-RT-DIST

- Decision: distributions, random_device, rand() and srand() are refused everywhere; std::hash only outside
  src/platform_*.cpp. A range-for is refused when its range expression names a std::unordered_* type or an identifier
  that is declared with such a type (or a `using` alias of one) anywhere in engine/runtime; the match is by name, so an
  ordered container of the same name elsewhere is a false positive that a rename removes.
- Why: no type information; ARCH3-R087 forbids all of these on deterministic paths.
- Where: runtime_lint.py `dist_findings`, `unordered_names`.
- Rule or table: ARCH3-R087.

## R-RT-PLATFORM

- Decision: applied to every file of engine/runtime outside a file directly in src/ named platform_*.cpp (testing/ and
  tools/ included). `std::thread::` scope members (std::thread::id, std::thread::hardware_concurrency()) and the value
  type std::filesystem::path are not flagged; constructing std::thread or std::jthread, other std::filesystem names,
  fopen, `::open(`, `::now(`, std::ifstream/ofstream/fstream are.
- Why: a path or a thread id performs no I/O and no thread creation; ARCH3-R035 says "no runtime file".
- Where: runtime_lint.py `_PLATFORM`, `platform_findings`.
- Rule or table: ARCH3-R035.

## R-RT-NOEXCEPT

- Decision: a lambda without noexcept is refused when the statement that holds it (back to the previous `;` or the `{`
  of the enclosing block) names job_desc, system_desc, add_task, add_system, add_method, submit, try_submit, on_event,
  subscribe, an identifier containing `invoker` or `handler`, or `.fn =`. A lambda first bound to a variable and passed
  later is not seen.
- Why: the brief gives the shape of a lambda but not the call contexts; SL-ARCH-003 names no invoker or handler API yet.
- Where: runtime_lint.py `_NOEXCEPT_CONTEXT`, `_call_context`, `noexcept_findings`.
- Rule or table: ARCH3-R010, ARCH3-R061.

## R-RT-OUTPUT

- Decision: a script line is tokenised with shlex; redirections (>, >>, &>, >|), `-o`, `--output`, `--out`,
  `--evidence-dir`, `--output-dir`, mkdir, tee, touch, cp, mv and install targets must resolve under build/: a literal
  `build/...`, a path with a `/build` segment, or a variable assigned such a value earlier in the script. Descriptor
  duplication, /dev/null, /dev/stdout, /dev/stderr, /dev/tty, heredoc bodies and `-o` of grep, ls, sed, awk, find, git,
  sort, stat, ps and rg are skipped.
- Why: the brief lists redirections, -o, --evidence-dir, mkdir, cp and tee; mv, touch, install and the other option
  spellings write files the same way.
- Where: runtime_lint.py `output_findings`, `_line_findings`, `_command_findings`.
- Rule or table: ARCH3-R015.

## contracts_check

- Decision: (1) R-RT-WO also reads work-orders/WO-nnn.md: the file must list the id as a `- RT-INV-...` line and a work
  order may not list an id the table gives to another owner or omits (both ways); the repository satisfies this today.
  (2) R-RT-AREA tests `startswith(area)` on the row's .cpp basename and exempts `stress_*` files. (3) `test` must be a
  tests/{unit,integration}/runtime .cpp or tools/runtime/test_*.py path (no `just` form, unlike the fabric checker).
  (4) The AREA list is parsed from the document's "AREA one of ... ," sentence, with the 26 areas built in as fallback.
  (5) sl-data blocks and recipe state (stub recipes, dispatch stub scripts) come from tools/governance
  (cmd_constitution_check.sl_data_blocks, cmd_contracts_pending.recipe_state), as the fabric checker does, so the
  checker and `just contracts-pending` agree on what is a stub.
- Why: "both ways" and "one owner WO" are not spelled out in the brief.
- Where: contracts_check.py `check`, `load_document`, `work_order_lists`.
- Rule or table: ARCH3-R014; table `invariants`.

## Gates

  error.hpp which is overwritten in the copy); neg_runtime_contracts.sh adds a third plant (a second file naming

  scripts `cd` to the repository root before running.
- Why: isolation per rule, and the recipes run from any directory.
- Where: tests/gates/neg_runtime_lint.sh, tests/gates/neg_runtime_contracts.sh, scripts/runtime/*.sh.
- Rule or table: ARCH3-R014, ARCH3-R015.
