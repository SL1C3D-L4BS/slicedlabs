Builder brief:
tree.hpp: trie key = first 16 bytes of SHA-256("slf-key/1" || id); radix 16 by nibble; node = u16 bitmap + entries
  (leaf: id + record or tombstone oid; child: node oid); a subtree with 32 or fewer entries is one leaf bucket sorted
  by key, so the shape depends only on the entry set (ARCH1-R51); nodes are SLB/1 values framed as kind tree.
revision.hpp: revision via the generated fabric.history type; root object (kind root) = struct {1 records trie oid, 2
  membership map oid}; membership map = trie of document id -> trie of member ids.
snapshot.hpp: immutable, cheap to copy, thread-safe reads: get(id) -> result<record_view> (verifies object ids via the
  backend), for_each_in_document(doc, f) via the membership map, diff(other) -> result<std::vector<record_delta>>
  skipping equal subtrees, root_digest(), revision_digest(); implements state_reader (WO-043) and record_enumerator
  (WO-044).
revision_builder: from a base snapshot plus staged record changes produce {new objects, root, revision} and a
  commit_batch with no ref moved; schema_set digest from the codec (WO-041).
Golden fixtures tests/fixtures/fabric/tree/roots.json (root digests of seeded entry sets) with MANIFEST.json.
