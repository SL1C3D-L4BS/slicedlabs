Builder brief:
impact.hpp: class impact_engine : commit_observer { static result<std::shared_ptr<impact_engine>>
  attach(transaction_manager&, const snapshot& head); result<impact_set> impact(std::span<const record_id> changed)
  const; result<bool> is_current(const record_id& derived, const snapshot& head) const; }; on_commit applies
  record_delta incrementally to the dependency_graph (WO-044) and attaches an impact_summary (counts per id class:
  asset, entity, instance, derived, plus test and build-target records by type) to the receipt via receipt_builder and
  to the committed event; is_current is false iff an input digest pinned in the derived record's provenance differs
  from the head digest; read failures are errors (ADR-0009).
Determinism: impact nodes ordered by (distance, id); summary lists at most 64 ids per class plus counts; the observer
  runs after the commit point and never fails a commit (an internal error is logged and the index marked for rebuild
  on next query).
The engine is attached explicitly by the caller (tests, the WO-062 demo); the workspace does not attach it implicitly
  in Volume 04.
Tests: integration impact_incremental_test FAB-INV-IMP-01 (incremental equals full rebuild after every commit of a
  seeded workload), impact_bounded_test IMP-02, impact_currency_test IMP-03, impact_receipt_test IMP-04.
