allocators.hpp (namespace sl::runtime::mem), every class derives mem::resource and passes run_allocator_contract:
  arena_resource(resource& upstream, std::size_t block_bytes = 65536, std::size_t capacity_bytes = 0 /*0 grows*/,
  memory_tag tag = {}): struct marker {std::size_t block, offset;}; marker mark() const; void rewind(marker) noexcept;
  void reset() noexcept; std::size_t used() const; release() is a no-op except for the last block (LIFO tail);
  arena_exhausted when capacity_bytes is reached and no upstream growth is allowed.
  stack_resource(resource& upstream, std::size_t capacity_bytes, memory_tag): push_marker()/pop_marker(); release
  must be LIFO: an out-of-order release is SL_ASSERT (assertions list).
  pool_resource(resource& upstream, std::size_t block_size /*>= 16*/, std::size_t block_align /*<= 4096*/, memory_tag):
  64 KiB slabs, intrusive LIFO free list, a request larger than block_size is invalid_argument; free_space_stats()
  reports free bytes and the largest run of contiguous free blocks in one slab.
  frame_arena(resource& upstream, std::uint32_t workers, std::size_t block_bytes = 1048576): two buffer sets A/B, each
  with one arena per worker plus one for the owner thread; resource& for_worker(std::uint32_t k) (k = workers is the
  owner thread); void flip() noexcept (owner thread, end_frame slot arena_flip): resets and poisons/fills the set that
  was current two flips ago, so frame-N memory stays valid through the end_frame of N+1 (ARCH3-R050); growth beyond
  block_bytes allocates from upstream and is counted (WO-089 asserts zero after warm-up).
  synchronized_resource(resource& inner) (std::mutex around inner; any thread); general_resource(
  std::pmr::memory_resource* upstream = std::pmr::new_delete_resource(), memory_tag) (any thread iff upstream is).
  Owner-thread resources capture std::this_thread::get_id() at construction (per-worker frame arenas: at the first
  allocation after a flip) and SL_DEBUG_ASSERT it on every call.
  Recycling resources fill (0xCD on allocate, 0xDD on release or reset) and ASan-poison released and reset ranges.
