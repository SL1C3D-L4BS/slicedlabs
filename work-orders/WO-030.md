Design (C++23, no gnu extensions, Werror in ci): `sl/core/log.hpp` (levels trace..fatal; `sl::log::event` with typed fields via a small variant {int64, double, bool, string_view}; correlation fields: scope tag or entity id placeholder, system name, tick placeholder (F6 seed: every event carries `scope` and `correlation_id`); sinks: stderr text, JSON lines (one object per line matching schemas/sl-log-event.schema.json), in-memory ring for tests; thread-safe via a mutex now, lock-free later), `sl/core/error.hpp` (`enum class errc` with domains core/platform/gfx/..., `sl::error` {errc, message, source_location}, `template<class T> using result = std::expected<T, sl::error>`), `sl/core/assert.hpp` (`SL_ASSERT`, `SL_VERIFY`: on failure emit a fatal log event with file:line and a stack trace when `__cpp_lib_stacktrace` and -lstdc++exp link succeed, then std::abort; `SL_ASSERT_REPORT_JSON=1` writes build/.../assert-report.json), unit tests for each (doctest), sl_sandbox logs its build info as events. tools/diagnostics/log_schema_check.py (`log-schema-check`: run sl_tests with the JSON sink to a file and validate every line against the schema). neg_log_schema.sh plants a malformed event in a copy's test and asserts the check names the field. ADR-0009 (Accepted-by-founder-order pending): std::expected over exceptions in engine hot paths; regenerate the ADR log.
